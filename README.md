# TapTap 每日新增游戏报告

TapTap 游戏榜单数据的每日新增下载可视化报告，每日自动更新。

- [主站每日新增](https://hellozerozone.github.io/taptap-report/) — TapTap 主站 24 个榜单游戏
- [TapTap Maker 每日新增](https://hellozerozone.github.io/taptap-report/maker.html) — Maker 自制游戏平台

数据来源：[TapTap](https://www.taptap.cn) 公开 API，仅供个人学习研究使用。

## 开源

抓取代码与全部历史数据以 [MIT 许可证](LICENSE) 开源在 [`source/`](source/) 目录，随报告每日更新。
